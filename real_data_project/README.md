# Real Data E-commerce User Behavior Project

## 项目简介

本项目是电商用户行为分析项目的第二阶段，计划基于真实用户行为数据进行分析、建模和推荐系统评估。

相比 `baseline_project`，本项目将重点从“跑通流程”升级为“贴近真实业务场景”。

## 主要目标

1. 接入真实电商用户行为数据；
2. 使用 SQL 和 pandas 完成用户行为探索性分析；
3. 使用 SQLite 进行本地 SQL 指标分析练习；
4. 分析用户首次兴趣行为后的延迟购买转化规律；
5. 比较浏览、收藏、加购等不同行为对应的后续购买率；
6. 基于延迟购买分析结果，为后续购买预测建模和推荐策略优化提供特征依据。

## 当前进度

当前已完成：

- 读取真实用户行为数据，并抽样生成 `user_behavior_100k.csv`；
- 将样本数据导入 SQLite，生成本地数据库 `user_behavior.db`；
- 使用 SQL 完成行为分布、DAU、每日核心指标、商品转化率、类目转化率和用户活跃度分层分析；
- 使用 pandas 复现部分 SQL EDA 指标，并保存中间结果；
- 完成首次兴趣行为后的延迟购买分析，包括未来 1/3/7 天累计购买率、不同首次兴趣行为的购买率、购买延迟分布。

## 项目结构

- `data/raw/`：原始真实数据，通常不上传 GitHub；
- `data/sample/`：抽样后的小规模数据，可用于演示和调试；
- `data/processed`/：清洗后数据、SQLite 数据库和中间结果；
- `src/`：Python 数据处理、建模和推荐代码；
- `sql/`：SQL 分析脚本；
- `docs/`：分析记录和项目报告；
- `notebooks/`：可选的探索性分析 notebook。

## 注意事项

真实数据文件可能较大，不应直接上传到 GitHub。后续会通过 `.gitignore` 忽略原始大文件，仅保留代码、文档和必要的小样例数据。

`data/processed/` 中的数据库文件和中间结果文件可由脚本重新生成，因此默认不上传 GitHub。
