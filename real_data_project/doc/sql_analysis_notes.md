# SQL 分析记录

## 1. 分析数据范围

本阶段使用 `user_behavior_100k.csv` 作为真实数据样本，并将其导入 SQLite 数据库进行 SQL 分析。

在日期检查中发现，样本前部存在少量早于主要时间范围的边界数据。为了避免异常日期影响趋势分析，后续核心分析主要使用以下时间窗口：

2017-11-25 至 2017-12-03

## 2. 行为分布分析

在主时间窗口内，用户行为分布如下：

| behavior_type | behavior_count | behavior_ratio |
| ------------- | -------------: | -------------: |
| pv            |          88295 |         0.8970 |
| cart          |           5362 |         0.0545 |
| fav           |           2701 |         0.0274 |
| buy           |           2075 |         0.0211 |

从结果可以看出，浏览行为占比最高，约为 89.70%；购买行为占比仅约为 2.11%。这符合电商平台常见的用户行为特征，即用户会产生大量浏览行为，但最终购买行为相对较少。

该结果说明用户从浏览到购买存在明显流失，也提示后续购买预测任务存在类别不平衡问题。因此，在模型评估时不应只关注准确率，还需要关注 Precision、Recall、F1、AUC 等指标。

## 3. 每日核心指标分析

本项目进一步统计了每日总行为数、每日活跃用户数、购买用户数和购买次数。

从结果看，2017-11-25 至 2017-12-03 期间，每日活跃用户数大致在 600 到 900 之间波动，每日购买用户数大致在 120 到 170 之间。2017-12-02 和 2017-12-03 的行为数和活跃用户数相对更高，说明样本中后期用户活跃程度有所提升。

在每日购买用户转化率分析中，使用以下指标衡量活跃用户中的购买占比：

每日购买用户转化率 = 当日购买用户数 / 当日活跃用户数

该指标可以避免只看购买次数带来的误导，因为购买次数较高可能只是由于当日活跃用户更多。通过购买用户转化率，可以更直接地观察不同日期用户的购买倾向。

## 4. 商品与类目转化率分析

在商品维度，本项目统计了每个商品的浏览次数、购买次数和购买转化率：

商品购买转化率 = 商品购买次数 / 商品浏览次数

为了避免低浏览量商品造成转化率虚高，分析时仅保留浏览次数不少于 20 次的商品。该分析可以帮助识别高转化商品，也可以发现高浏览但低购买的商品，为商品运营和推荐策略提供参考。

在类目维度，本项目统计了每个类目的浏览次数、购买次数和购买转化率，并仅保留浏览次数不少于 50 次的类目。相比单个商品，类目维度结果更稳定，可以用于观察不同品类之间的整体购买倾向。

商品和类目转化率分析也为后续建模提供了特征思路，例如商品历史购买转化率、类目历史购买转化率、商品热度和类目热度等。

## 5. 用户活跃度分层分析

本项目根据用户在主时间窗口内的总行为次数，将用户划分为三类：

| 用户层级      | 划分规则                         |
| ------------- | -------------------------------- |
| high_active   | total_behavior_count >= 100      |
| middle_active | 30 <= total_behavior_count < 100 |
| low_active    | total_behavior_count < 30        |

用户分层结果如下：

| active_level  | user_count | avg_behavior_count | avg_active_days | buy_user_count | buy_user_rate |
| ------------- | ---------: | -----------------: | --------------: | -------------: | ------------: |
| high_active   |        362 |             189.52 |            8.16 |            284 |          0.78 |
| middle_active |        434 |              60.90 |            6.88 |            288 |          0.66 |
| low_active    |        187 |              18.16 |            5.08 |             97 |          0.51 |

从结果可以看出，用户活跃度越高，购买用户占比越高。高活跃用户中约 78% 在样本窗口内发生过购买，而低活跃用户中约 51% 发生过购买。

这说明用户活跃度与购买倾向存在明显正相关。后续在购买预测模型中，可以将用户总行为次数、活跃天数、历史购买次数等作为重要用户特征。
