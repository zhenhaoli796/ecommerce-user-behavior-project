# 数据说明

## 原始数据

本项目第二阶段使用淘宝用户行为数据集 `UserBehavior.csv`。

原始数据字段如下：

| 字段          | 含义         |
| ------------- | ------------ |
| user_id       | 用户 ID      |
| item_id       | 商品 ID      |
| category_id   | 商品类目 ID  |
| behavior_type | 用户行为类型 |
| timestamp     | Unix 时间戳  |

行为类型说明：

| 行为类型 | 含义             |
| -------- | ---------------- |
| pv       | 浏览商品详情页   |
| fav      | 收藏商品         |
| cart     | 将商品加入购物车 |
| buy      | 购买商品         |

## 样本数据

由于原始数据文件较大，本项目先从原始数据中读取前 100000 行，保存为样本数据：

`data/sample/user_behavior_100k.csv`

样本数据用于后续 pandas 分析、SQLite 导入、SQL 指标练习和建模流程验证。

## 样本行为分布

前 100000 行样本中的行为分布如下：

| behavior_type | count |
| ------------- | ----: |
| pv            | 89709 |
| cart          |  5446 |
| fav           |  2744 |
| buy           |  2101 |

从样本分布可以看出，浏览行为占绝大多数，购买行为占比较低，符合电商平台常见的用户行为特点。
