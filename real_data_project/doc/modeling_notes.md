# 购买预测模型说明

## 建模目标

预测用户对某商品产生首次兴趣行为后，是否会在未来 3 天内购买该商品。

## 样本与标签

- 候选样本：用户对商品的首次 pv、fav 或 cart 行为；
- 标签：首次兴趣行为后的未来 3 天内是否出现 buy；
- 为保证标签完整，只保留首次兴趣时间不晚于 2017-11-30 的样本；
- 最终特征表共 47,318 条样本，购买正样本 772 条。

## 特征

模型使用 22 个特征，包括：

- 首次兴趣行为类型；
- 兴趣行为发生时间；
- 用户历史浏览、收藏、加购、购买次数；
- 商品历史浏览、收藏、加购、购买次数；
- 类目历史浏览、收藏、加购、购买次数。

所有历史特征只统计首次兴趣行为发生之前的数据，避免使用未来信息。

## 训练与评估

按时间切分数据：

- 训练集：2017-11-25 至 2017-11-27；
- 验证集：2017-11-28；
- 测试集：2017-11-29 至 2017-11-30。

第一版模型使用 StandardScaler 和 class_weight="balanced" 的逻辑回归。

在验证集上比较多个阈值，并以 F1 最高的阈值作为最终分类阈值。最终选择阈值为 0.7。

## 测试集结果

| 指标      |   结果 |
| --------- | -----: |
| Accuracy  | 0.8801 |
| Precision | 0.0537 |
| Recall    | 0.3582 |
| F1        | 0.0934 |
| ROC-AUC   | 0.7467 |
| PR-AUC    | 0.0517 |

测试集购买率约为 1.72%，PR-AUC 明显高于随机基线，说明模型具备一定购买样本排序能力。

## 初步结论

- 首次加购和收藏比首次浏览具有更强的后续购买信号；
- 历史购买用户的后续购买倾向更高；
- 类目历史加购和购买行为可作为类目热度信号；
- 购买样本比例较低，后续应继续比较树模型，并针对业务成本选择预测阈值。
