# 延迟购买分析记录

## 1. 分析目标

本分析关注用户从首次产生兴趣到最终购买之间的时间关系。

这里将用户对商品的非购买行为定义为兴趣行为，包括：

- pv：浏览
- fav：收藏
- cart：加购

购买行为 `buy` 被视为转化结果。

本分析主要回答以下问题：

1. 用户首次对商品产生兴趣后，未来 1 天、3 天、7 天内的累计购买率是多少？
2. 不同首次兴趣行为对应的未来购买率是否存在差异？
3. 已发生购买的用户-商品中，购买通常发生在首次兴趣后的多久？

## 2. 首次兴趣行为定义

本项目以 `user_id + item_id` 为粒度，统计每个用户对每个商品在样本窗口内第一次出现的非购买行为，作为首次兴趣行为。

需要注意的是，由于当前使用的是样本数据，首次兴趣行为指在样本窗口中观测到的首次非购买行为，不一定代表用户完整历史中的第一次行为。

## 3. 未来 1/3/7 天累计购买率

为了保证不同样本之间的观察窗口公平，在计算未来 N 天购买率时，仅保留首次兴趣时间距离数据截止日不少于 N 天的样本。

分析结果如下：

| window | sample_count | buy_count | buy_rate |
| ------ | -----------: | --------: | -------: |
| 1d     |        66734 |       858 |   0.0129 |
| 3d     |        48486 |       781 |   0.0161 |
| 7d     |        17609 |       344 |   0.0195 |

从结果可以看出，随着观察窗口从 1 天扩大到 3 天、7 天，累计购买率从 1.29% 提升到 1.95%。这说明部分用户不会在首次产生兴趣后立即购买，而是存在一定的延迟转化。

同时，随着观察窗口变长，可用于完整观察的样本数量减少。因此在比较不同时间窗口购买率时，需要同时关注样本数量变化。

## 4. 不同首次兴趣行为的购买率

本项目进一步比较了不同首次兴趣行为对应的未来 3 天购买率。

结果如下：

| first_behavior_type | sample_count | buy_count | buy_rate |
| ------------------- | -----------: | --------: | -------: |
| cart                |         2821 |       160 |   0.0567 |
| fav                 |         1536 |        51 |   0.0332 |
| pv                  |        44129 |       570 |   0.0129 |

从结果可以看出，首次兴趣行为越强，未来 3 天购买率越高。其中，首次行为为加购的购买率最高，为 5.67%；首次行为为收藏的购买率为 3.32%；首次行为为浏览的购买率最低，为 1.29%。

这说明用户行为类型可以反映购买意向强弱。后续如果进行购买预测建模，可以将行为类型、行为次数和行为权重作为重要特征。

## 5. 购买延迟分布

本项目进一步统计了发生购买的用户-商品中，从首次兴趣行为到首次购买之间的时间间隔。

结果如下：

| delay_bucket | buy_count |
| ------------ | --------: |
| 0-1d         |       946 |
| 1-3d         |       158 |
| 3-7d         |        86 |
| 7d+          |         5 |

从结果可以看出，大多数购买发生在首次兴趣后的 1 天内。超过 3 天后再发生购买的样本数量明显减少。

该结果说明，用户兴趣产生后的短时间窗口是购买转化的关键阶段。对于电商平台而言，可以在用户浏览、收藏或加购商品后的 1 天内进行及时触达，例如购物车提醒、优惠券推送、降价提醒或个性化推荐，从而提升转化效率。

## 6. 分析结论

综合以上结果，本项目得到以下结论：

1. 用户首次产生兴趣后，购买转化率整体较低，但会随着观察窗口扩大而上升；
2. 加购和收藏行为相比普通浏览更能反映购买意向；
3. 大多数购买发生在首次兴趣后的 1 天内，及时触达可能更有效；
4. 延迟购买分析可以为后续购买预测建模和推荐策略优化提供特征依据。
